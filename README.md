# Personal Calendar Agent

An intelligent Personal Calendar AI Agent built using Anthropic's official Python SDK **`claude-agent-sdk` (v0.2.128)**, In-process **Model Context Protocol (MCP)**, and **AWS Bedrock** integration.

---

## 🌟 Key Features & Architecture

### 1. Official `claude-agent-sdk` & In-Process MCP Architecture
* **`@tool` Decorator & Pydantic Schema (`tools/`)**: Uses `claude_agent_sdk.tool` decorator and Pydantic `BaseModel` for type-safe input/output argument validation and automatic JSON Schema generation.
* **In-Process MCP Server (`create_sdk_mcp_server`)**: Implements SDK-native In-Process MCP Servers running directly inside the Python process (`mcp_servers={"calendar": calendar_mcp_server}`) without requiring external daemon processes.
* **`ClaudeAgentOptions` & `query` Engine (`agent/core.py`)**: Asynchronous agent inference loop, automatic tool execution, observation collection, and streaming response parsing.

### 2. Full AWS Bedrock Integration (`CLAUDE_CODE_USE_BEDROCK=1`)
* Injects `CLAUDE_CODE_USE_BEDROCK=1` and AWS IAM environment variables to seamlessly run the agent over **AWS Bedrock endpoints** as well as direct Anthropic API.
* Applies `thinking={"type": "disabled"}` option to prevent API Error 400 caused by extended thinking block mismatches during multi-turn tool loops.

### 3. Dynamic Date Mapping Injection (Preventing LLM Hallucinations)
* Dynamically injects a **real-time [This Week / Next Week YYYY-MM-DD Mapping Table]** generated by Python `datetime` operations into the System Prompt. This 100% eliminates LLM date hallucinations (e.g. mapping "this Saturday" to past cutoff years like 2023) — see [BUG_FIX.md](file:///Users/jason/dev/ai/my-personal-calendar-agent/BUG_FIX.md).

### 4. Dynamic Multi-Lingual Response Policy
* **Language Matching**: Dynamically generates response content in the exact language used by the user (Korean prompt -> Korean response, English prompt -> English response).
* **System & Log Preservation**: Preserves terminal debug logs, system symbols (`[TOOL CALL]`, `[THOUGHT]`, `mcp__calendar__*`, ▶, ✔, ⏱, ■, ●, ◆, ℹ, ✖) in English regardless of the user's language.

### 5. Rich-Based CLI UI, Single-Width Unicode Symbols & Dynamic Spinner
* **Single-Width Unicode Symbols**: Replaces 2-cell wide emojis with single-width Unicode symbols (`▶`, `✔`, `⏱`, `■`, `●`, `◆`, `ℹ`, `✖`) to eliminate terminal column width distortion.
* **Dynamic Spinner & Step Log Accumulation**: Features a real-time status spinner (`⏱`) while persistently accumulating reasoning step logs and tool call panels on screen.

### 6. Project-Specific Custom Skill (`calendar-smart-scheduler`)
* Binds `ClaudeAgentOptions(skills=["calendar-smart-scheduler"], setting_sources=["user", "project"])` to automatically execute pre-creation conflict checks (`check_conflicts`), free slot discovery (`get_free_slots`), and standardized summary output.

### 7. Declarative User-Level MCP Expansion (`mcp.json` & `tools/mcp_loader.py`)
* **Declarative MCP Setup**: Allows users to specify custom MCP servers (e.g. filesystem, slack) and `allowed_tools` in [`mcp.json`](file:///Users/jason/dev/ai/my-personal-calendar-agent/mcp.json), which are safely merged with the built-in `calendar` MCP server at runtime.

## 🚀 Quick Start Guide (`uv`)

### 1. Environment Setup & Sync
Sync virtual environment and dependencies using `uv`:
```bash
uv sync
```

### 2. Configure AWS Bedrock Environment Variables
Copy `.env.example` to `.env` and set your AWS IAM credentials:
```bash
cp .env.example .env
```
Example `.env` content:
```env
AWS_ACCESS_KEY_ID=your_aws_access_key_id
AWS_SECRET_ACCESS_KEY=your_aws_secret_access_key
AWS_REGION=us-west-2
BEDROCK_MODEL_ID=us.anthropic.claude-sonnet-4-20250514-v1:0
```

### 3. Run Test Suite
```bash
uv run pytest
```

### 4. Start Personal Calendar Agent CLI
```bash
uv run main.py
```
